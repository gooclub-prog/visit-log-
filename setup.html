구글 시트 연결 안내

방문일지에 저장한 기록을 구글 시트에, 사진을 구글 드라이브에 자동으로 모으는 설정이에요. 처음 한 번만 하면 되고, PC에서 하시는 게 편해요. 15분쯤 걸려요.

  1. 구글 시트 만들기

    sheets.google.com에 들어가 기록을 모을 구글 계정으로 로그인하세요.

    + 빈 스프레드시트를 누르고, 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 방문일지로 바꾸세요.

  2. 코드 넣는 화면 열기

    시트 위쪽 메뉴에서 확장 프로그램 → Apps Script를 누르세요. 새 탭에 코드 편집 화면이 열려요.

  3. 코드 붙여 넣기

    편집 화면에 이미 적혀 있는 function myFunction() …을 모두 지우고, 아래 코드를 복사해서 붙여 넣으세요.

    코드를 불러오는 중…

    붙여 넣은 코드 위쪽의 const KEY = '여기에-비밀번호';에서 여기에-비밀번호 부분만 지우고 원하는 비밀번호를 적으세요(예: 'visit2026!'). 따옴표는 남겨 두세요. 이 비밀번호는 나중에 휴대폰 앱에도 똑같이 넣어요.

    다 했으면 위쪽 💾 저장 아이콘을 누르세요.

  4. 권한 허락하기

    위쪽 실행 버튼 옆의 함수 고르는 칸에서 setup을 고르고 ▷ 실행을 누르세요.

    권한 검토 → 내 계정 선택을 누르세요. "Google에서 확인하지 않은 앱"이라는 경고가 나오면, 원철님이 직접 만든 코드라서 나오는 정상 화면이에요. 왼쪽 아래 고급 → 방문일지(으)로 이동(안전하지 않음) → 허용을 누르세요.

    아래쪽에 "실행 완료"가 나오면 성공이에요. 시트에 방문기록 탭이, 드라이브에 방문일지 사진 폴더가 생겨요.

  5. 웹 앱으로 배포하기

    오른쪽 위 배포 → 새 배포를 누르세요.

    "유형 선택" 옆 톱니바퀴 ⚙ → 웹 앱을 고르세요.

    실행 사용자: 나, 액세스 권한이 있는 사용자: 모든 사용자로 고르고 배포를 누르세요.

    나오는 웹 앱 URL(https://script.google.com/macros/s/…/exec)을 복사하세요. 휴대폰으로 옮기려면 카카오톡 "나와의 채팅"에 붙여 보내면 편해요.

  6. 휴대폰 앱에 연결하기

    휴대폰에서 방문일지 앱을 열고 방문 목록 → 백업·시트를 누르세요.

    "구글 시트 자동 동기화"의 웹 앱 주소 칸에 복사한 URL을, 비밀번호 칸에 3단계에서 정한 비밀번호를 넣고 연결하기를 누르세요.

    "연결됨"이 나오면 끝이에요. 지금까지 저장한 기록도 자동으로 시트에 들어가고, 앞으로는 저장할 때마다 바로 들어가요. 인터넷이 안 될 때 저장한 기록은 "시트 전송 대기"로 표시됐다가 연결되면 다시 보내요.

PC에서는 그 구글 시트를 열면 기록이 보이고, 사진 칸의 링크를 누르면 드라이브의 사진이 열려요. 파일 → 다운로드 → Microsoft Excel로 엑셀 파일로도 받을 수 있어요.
